## 1. 访客（3 分钟，不登录）

入口：首页 → “以访客身份咨询”（`/#/guest`）。

1. 问“勤工助学的报酬标准是多少？”→ 展示回答、`[1]` 编号和“参考：…pdf”引用；强调“每句话都有出处”。
2. 问“国家助学金的资助标准是多少？”→ 展示多档标准与引用。
3. 问“火星校区的食堂在哪里？”→ 展示“没有在知识库找到…不做推测”的拒答，强调宁可拒答不编造。
4. 说明：访客不落库、不保存历史，按访客 cookie 限 10 次/分钟。

## 2. 学生（3 分钟，20230001 / Student@123）

1. 登录 → 历史记录里有 3 个预置会话：
   - 勤工助学的报酬标准是多少？
   - 家庭经济困难学生认定需要准备哪些材料？
   - 学费减免怎么申请？能减多少？
2. 打开“勤工助学”会话，展示历史回答与引用卡片；追问“那临时岗位怎么算？”展示多轮上下文。
3. 说明权限：学生只能看自己的会话；教务页只查本人数据（当前校方网络限制，展示引导/降级态即可，不承诺真实数据）。
4. 打开“教务查询”页：未绑定时显示绑定引导；如网络不可达，说明“教务系统暂时无法访问”的降级话术（不现场绑定）。

## 3. 管理员（3 分钟，admin / Admin@12345）

1. 登录 → 知识库管理：展示 21 份文件、状态、切片数；打开一份文件的“切片”抽屉，展示页码/章节元数据。
2. 打开“智能问答”预置会话（勤工助学/助学金/励志奖学金），展示管理员语气与引用。
3. 说明：管理员可管理知识库、不能看学生成绩明细；会话搜索本期不做，支持重命名/删除。
4. （可选）展示 `/metrics` 仅本机可见、公网 404；不现场演示上传大文件（20MB 经代理约 165 秒）。

## 4. 断网兜底

- 断外网只影响 AnySearch，静态知识库与 vLLM 仍在；访客问答可正常演示。
- 实演练过：把 `api.anysearch.com` 指黑洞，问答静默用知识库作答/拒答（`docs/18`）。
- 演示前可提前把常见问题预热，避免首条 LoRA 冷启动等待。
