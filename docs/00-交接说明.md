## 4. 已定型的关键设计（别推翻）

1. **级联检索**：先静态 RAG；top1 ≥0.80 且没要"最新"且无主题缺失就不联网，否则补 AnySearch；合并后统一重排，阈值 0.20、最多留 3 条。
2. **查询改写用官方术语**（不做同义词表）：路由一次产出意图 + 关键词；知识库文件名前 30 个作为"参考用词"注入（60s TTL）；关键词最高分 <0.50 视为改偏，用原句再检一次并合并。
3. **联网证据门禁**：正文 <80 字或无完整句的网页不进证据；**联网搜索用原句**（改写词常只命中首页，原句能搜到正文）。
4. **回答落地校验**（`services/grounding.py`）：书名号标题、带单位数字、"包括/如/例如"后的顿号列举必须在证据原文找得到；越界编号算违规。违规先就地重写，仍违规则删句，删空降级拒答；结果走 SSE `replace`。
5. **SSE**：`meta → delta* → [replace] → citation → done`，2.5s 一次 `: ping`（平台代理空闲 4 秒断流）；断线用 `asyncio.shield` 保住落库。
6. **配额三层**：24h 查询缓存 → 每用户 60/日 → 全局 1800/日；个人超限不消耗全局。
7. **轨迹落库**：`agent_trace` 表，一条消息一行，`GET /conversations/{id}/trace` 可复盘。
8. **编号收敛**：每句最多 2 个编号，按证据分保留，"参考："行不动（`clamp_citations`，不改提示词版本）。
9. **检索主题过滤**：`kb_file.topics` + `app/rag/topics.py`；主题不符的证据在合并前剔除；识别到主题但库内无文件 → 强制联网/拒答；识别不到主题不过滤。
10. **网页时效过滤**：`app/rag/freshness.py`，页面最新年份距今 ≥2 年剔除；**页脚 CopyRight/备案年份不算**；提取不到年份不判过时。
11. **弱证据门禁**：合并证据最高分 <0.30 且无主题匹配 → 直接拒答（`nodes.py: WEAK_EVIDENCE_SCORE`）。
12. **路由守卫**：含校园实体词（招生/放假/军训/宿舍/食堂/接站/气候…）的问题不允许落到 chitchat/unknown 自由发挥；含"最新/最近/今年/近期/通知/公告"强制补联网。
13. **限流与排队**：登录用户按 `user_id` 每分钟 10 次；访客按 `visitor_id` cookie（30 天）每分钟 10 次；同时生成 8 个、队列 3 个/最长 8s，超出 429 + `Retry-After`。**平台代理折叠来源 IP 且 XFF 可伪造，不能按 IP 限流**。
14. **可观测性**：`GET /metrics` 仅服务器本机可访问；`chat_metrics` 记录排队/首字/总时长/意图/证据数/降级；每秒采样事件循环延迟与 RSS；慢请求（非 SSE >3s）单独告警日志。

## 8. 已知坑（踩过，别再踩）

- 登录失败与令牌过期都是 `401 + code 2001`，前端必须特判 `/auth/login`。
- 检索差先怀疑**用词不一致**（同一片段口语 0.037 / 规范关键词 0.990），不要先怀疑向量化。
- **不要拿原句对 KB 结果二次重排**：会二次降分筛掉正确证据；只给联网结果补分。
- 往 `ref([])` push 普通对象再逐 token 改它不会触发渲染，必须 `reactive()`。
- 实例重启后 MySQL 不自启，`start.sh backend` 已内置拉起；**vLLM 首条问答 11.6s（LoRA 首次加载），演示前先预热**。
- MySQL 需 `cryptography`；`mysqldump` 要 `-h127.0.0.1 --no-tablespaces`，否则静默导出 20 字节空包。
- `oss` CLI 没有 bucket 名（`oss://` 即根），只收压缩包，`oss rm` 要 `-f`；登录态会过期（401），需重新 `oss login`。
- 前端构建在虚机本地盘（`/tmp/fe`）；Vite 8 `manualChunks` 只接受函数；部署前先 `rm -rf dist`。
- `pkill -f "npm install"`/`pkill -f build_sft_full` 会杀掉自己的 SSH 会话，用 `np[m]`、`build_sft_fu[l]l` 写法。
- PDF 页眉会把表格名切成两半，落地校验用二元组容忍。
- 训练 eval OOM：HF eval 默认 batch=8 × 3072 × 15 万词表 logits 要 5GB，必须 `per_device_eval_batch_size=1`；OOM 发生在存盘前会丢 checkpoint。
- `backup.sh` 本地清理曾因 glob 提前展开导致参数错位，改用带引号的 pattern。
- 网页页脚 `CopyRight 2022` 会被年份提取误判成过时，已忽略版权/备案段。
- **平台代理看不到真实 IP**：公网请求在日志里统一是 `172.17.0.1`，且 `X-Forwarded-For` 可被客户端伪造（伪造 `9.9.9.9` 会被 Uvicorn 采信）。不要按 IP 限流，访客用 `visitor_id` cookie（D-16）。
- **结构化日志会脱敏含 `token` 的字段名**：`first_token_ms` 会被整体打成 `******`，改用 `first_delta_ms`。
- **容器没有 systemd**：`systemctl` 看不到三服务，pid 在 `/hy-tmp/campus/run`；停止/启动用 `scripts/stop.sh` / `start.sh`，崩溃不会自动拉起（D-19）。
