# P9-03 备份与恢复演练报告

> 2026-11-15。独立恢复演练，不动生产、不停服。

## 1. 备份

| 产物 | 路径 | 大小 |
|---|---|---|
| MySQL 快照 | `/hy-tmp/campus/backup/p9-drill-db.sql.gz` | 185KB |
| Chroma 快照 | `/hy-tmp/campus/backup/p9-drill-chroma.tar.gz` | 2.1MB |

备份命令（与 `scripts/backup.sh` 同口径）：

```bash
cd /hy-tmp/campus/app
set -a; . backend/.env; set +a
mysqldump -h127.0.0.1 -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" --no-tablespaces --single-transaction --quick "$MYSQL_DB" | gzip > /hy-tmp/campus/backup/p9-drill-db.sql.gz
tar -czf /hy-tmp/campus/backup/p9-drill-chroma.tar.gz -C /hy-tmp/campus/data chroma
```

## 2. 恢复

```bash
env -u MYSQL_HOST -u MYSQL_USER -u MYSQL_PASSWORD mysql -uroot \
  -e "DROP DATABASE IF EXISTS campus_assistant_restore; CREATE DATABASE campus_assistant_restore DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci; GRANT ALL PRIVILEGES ON campus_assistant_restore.* TO 'campus'@'127.0.0.1'; FLUSH PRIVILEGES;"
gunzip -c /hy-tmp/campus/backup/p9-drill-db.sql.gz | mysql -h127.0.0.1 -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" campus_assistant_restore
rm -rf /tmp/chroma-p9-restore && mkdir -p /tmp/chroma-p9-restore
tar -xzf /hy-tmp/campus/backup/p9-drill-chroma.tar.gz -C /tmp/chroma-p9-restore
```

> 注意：`.env` 导出的 `MYSQL_HOST` 会被 mysql 客户端读取，root 走 socket 时要 `env -u MYSQL_HOST -u MYSQL_USER -u MYSQL_PASSWORD`。
