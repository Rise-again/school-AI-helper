# 云资源与预算

> 按 2026-11-08 恒源云 **RTX 4090 24GB** 西北区报价（活动价 ¥1.66/小时，原价 ¥1.95）估算，下单前以实际页面为准。

## 1. 需要什么

| 资源 | 规格 | 用途 |
|---|---|---|
| 实例 | RTX 4090 24GB / 16 核 / 62GB 内存 / 系统盘 20GB + 数据盘 50GB（建议扩到 100GB）/ 800Mbps | 训练、推理、后端、MySQL、Chroma 全部同机 |
| 个人数据（OSS） | 按量，约 ¥0.0004/GB/小时（≈¥0.29/GB/月） | 每日备份、模型与镜像归档 |
| 域名 / 证书 | 不需要 | 用平台自定义服务 HTTPS 链接 |

## 2. 成本估算

| 项 | 用量 | 单价 | 小计 |

| 开发期按需开机 | 约 120 小时（联调时段） | ¥1.66/h | ¥199 |
| 训练（QLoRA 6–10 小时） | 与开发机同一台 | ¥1.66/h | ¥17 |
| 压测与验收期常驻 | 11/27–12/06，240 小时 | ¥1.66/h | ¥398 |
| 个人数据存储 | 约 100GB × 1 个月 | ¥0.29/GB/月 | ¥29 |
| **合计** | | | **≈ ¥650**（含数据盘扩容约 ¥30） |

若开发期几乎全程开机（11/10–12/06 共 648 小时），总计约 ¥1240。两种节奏都在预算内。

## 3. 便宜在哪

平台自定义服务省掉了：域名（¥30–80/年）、证书（免费但要折腾）、备用服务器（¥600–960/10 天）。相比自建海外节点方案，成本降低约 40%，还少了备案这条长周期风险。

## 4. 省钱与止损

1. **按天开、按天关**：开发期只在联调当天开机，结束即关。关机前确认数据已备份到 OSS（`/hy-tmp` 24 小时后清空）。
2. **训练不单独租**：QLoRA 在 48GB 卡上跑，和推理共用一台，训练完直接切回推理。
3. **环境用备份镜像固化**：重装一次的成本是 40 分钟，做镜像后可省掉。
4. 余额保持充足：欠费 15 天会删除个人数据与自定义镜像。

| 阈值 | 动作 |
|---|---|
| 累计 ¥800 | 复核开机时长，检查是否有忘记关机的实例 |
| 累计 ¥1200 | 改为演示当天开机，其余时间本地开发 |
| 累计 ¥1800 | 强制止损，改用本地 LAN 演示 + 录屏 |

## 5. 待你确认

1. 生产实例按小时还是包天/包周（平台支持"包天/包周/包月"，通常比按小时便宜）。
2. 预算上限取 ¥1200 还是 ¥1800。
