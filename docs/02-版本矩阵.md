## 3. 云端后端依赖（`backend/requirements-linux.txt`）

与第 2 节基本一致，差异点：`uvloop` 不装（保持与开发一致的行为）、chromadb 在 Linux 上用同一版本。生产额外装 `gunicorn`？**否**——单 worker 用 uvicorn 直接托管，不引入进程管理器。

## 4. 云端模型服务依赖（`model_service/requirements-linux.txt`）

| 包 | 版本 | 用途 |
|---|---|---|
| fastapi / uvicorn | 同上 | 模型服务的 HTTP 外壳 |
| FlagEmbedding | 1.4.2 | 载入 bge-large-zh-v1.5 与 bge-reranker-v2-m3 |
| torch | 2.8.0+cu128（随 vllm 环境） | 推理后端；**不能用镜像自带的 2.9.1**，vllm 0.11 要求 2.8.x |
| paddlepaddle（**CPU**）/ paddleocr | 3.3.1 / 3.7.0 | OCR；PyPI 无 cp311 的 GPU 3.x 轮子，按计划降级到 CPU 通道 |
| pillow | 最新稳定 | 图像预处理 |
| vllm | **0.11.0** | 单独进程，OpenAI 兼容。0.31.0 依赖 torch 2.13+cu130，驱动 570（最高 CUDA 12.8）跑不起来，实测 `cuda_available=False` |
| transformers | **4.57.1**（钉住） | vllm 0.11 与 transformers 5.x 不兼容，会报 `Qwen2Tokenizer has no attribute all_special_tokens_extended` |

> **训练栈与推理栈必须分离**：Llama-Factory 从源码安装（`pip install -e .`），其 `transformers` 版本由框架自身的 requirements 决定，不能与推理环境共用。训练环境用独立镜像，训练完只把 adapter（几十 MB）带出来。`transformers` 当前主流为 5.x，与微调框架的兼容性**必须在训练机实测确认**，不要凭版本号假设。

## 7. 锁定规则

1. 上表版本写入三份 requirements，任何升级须单独提交并说明原因。
2. 首次安装成功后回填 `pip freeze` 结果，替换为精确 `==`。
3. 训练栈版本单独记录在 `model_service/TRAINING_VERSIONS.md`，不进推理环境。
4. 出现"必须升级才能解决"的情况，先评估对已验证功能的影响，再走变更记录。

## 8. 实测版本（2026-11-08，恒源云实例）

实例：Ubuntu 22.04.5 / RTX 4090 24GB（24564 MiB）/ 驱动 570.211.01 / 系统 Python 3.11.12。

| 环境 | 位置 | 关键版本 | 锁文件 |
|---|---|---|---|
| web（后端） | `/hy-tmp/campus/venvs/web` | fastapi 0.162.0、chromadb 1.5.9、aiomysql 0.3.2、cryptography 46+ | `backend/requirements-linux.lock`（110 个包） |
| vllm（推理） | `/hy-tmp/campus/venvs/vllm` | vllm 0.11.0、torch 2.8.0+cu128、transformers 4.57.1 | `model_service/requirements-vllm.lock`（155 个包） |
| models（功能模型） | `/hy-tmp/campus/venvs/models` | FlagEmbedding 1.4.2、paddlepaddle 3.3.1（CPU）、paddleocr 3.7.0、复用系统 torch 2.9.1 | `model_service/requirements-models.lock` |

踩坑记录（都已写进部署手册）：
1. `python3 -m venv` 报 ensurepip 失败 → 用 virtualenv。
2. MySQL 8 默认 caching_sha2 认证 → 后端需要 `cryptography`。
3. `aiomysql` 0.3.x 不再导出 `constants` → 从 `pymysql.constants` 取 CLIENT。
4. vllm 0.31 → CUDA 13 → 驱动不支持，降到 0.11。
5. FlagEmbedding 1.4.2 的 `encode()` 不接受 `normalize_embeddings` → 自己做 L2 归一化。
