## 1. 决策

| 项 | 结论 | 日期 | 理由 |
|---|---|---|---|
| 部署地域 | **海外节点** | 2026-11-07 | 大陆绑域名需 ICP 备案 7–20 工作日，课程交付等不起 |
| 备案 | 不需要 | 2026-11-07 | 海外节点无备案义务 |
| 反向代理 | 不引入 | 2026-11-07 | 选型冻结；TLS 由 uvicorn 直接终止 |
| 对外端口 | 443（业务）、22（SSH，限来源 IP） | 2026-11-07 | 8001/8002 只监听 127.0.0.1 |

代价：国内用户访问延迟约 150–300ms；访问境内教务系统会更慢，且有被风控的可能（见计划风险 R9）。

## 2. 你需要做的事（按顺序）

1. **买域名**（阿里云/腾讯云/Namecheap 均可），完成实名认证。约 ¥30–80/年。
2. **加两条解析记录**：
   - `A` 记录：`@` → 生产机公网 IP
   - `A` 记录：`www` → 同一 IP（可选）
3. **申请免费证书**：选 DNS 验证方式。厂商会给你一条 `TXT` 记录（形如 `_dnsauth` → 一串字符），**加完后告诉我，我来验证并下载证书**。
4. **安全组/防火墙**：只放行 443 和 22，22 建议限制来源 IP。
5. 服务器开通后把 **IP、SSH 用户名、密钥文件路径** 给我（密码不要发在对话里）。

## 3. 我负责的部分

- 证书申请命令、DNS 记录校验（`nslookup -type=TXT`）
- nginx 不装，直接给 uvicorn 的 TLS 启动参数与 systemd 单元
- 证书到期前的续期检查清单
- 安全组规则清单与验证方法（从外网扫端口）
