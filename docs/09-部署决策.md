# 部署决策记录（P0-08）

> 2026-11-07 定稿。此前"海外节点 + 自购域名 + 证书"的方案已作废（D-01 → D-06）。

## 1. 决策

| 项 | 结论 | 依据 |
|---|---|---|
| 算力平台 | **恒源云（gpushare）** | 已选好 L40S 48GB，¥1.87/小时 |
| 地域 | 华东（国内） | 访问学校教务系统快，无异地登录风控 |
| 对外访问 | **平台"自定义服务"**，平台提供 HTTPS 链接 | 免备案、免自购域名与证书 |
| 服务端口 | **8080**，监听 `0.0.0.0` | 平台硬性要求，写 `127.0.0.1` 或换端口都不通 |
| 域名/证书 | 不购买 | 平台子域名 + 平台证书足够，课程交付无需独立域名 |
| 环境固化 | **备份镜像**（实例管理 → 创建备份镜像） | 环境一次装好，后续实例直接从镜像创建 |
| 数据持久化 | 每日 `oss cp` 到"个人数据" | `/hy-tmp` 关机 24 小时后清空；个人数据长期保留（欠费 15 天后删除） |
| 反向代理 | 不引入 Nginx | 前端静态文件由 FastAPI 托管，前后端同端口 |

## 2. 平台生命周期要点（决定运维动作）

| 事件 | 后果 | 应对 |
|---|---|---|
| 关机超过 24 小时 | `/hy-tmp` 数据删除 | 每日备份到个人数据 OSS；开机先检查再启动 |
| 按量关机 / 包周期到期超过 10 天 | 实例删除 | 交付期保持开机或及时续费 |
| 欠费满 15 天 | 个人数据、共享存储、自定义镜像全部删除 | 保持余额充足；重要数据本地留一份 |
| 实例迁移 | `/hy-tmp` 清空 | 迁移前先备份 |

## 3. 访问形态

答辩与验收统一使用控制台的"自定义服务"链接（`https://...`）。风险：链接随实例存在，关机即失效，所以演示当天必须开机、提前 5 分钟预热（vLLM 冷启动 1–3 分钟）。备用方案是本地 LAN 演示 + 录屏。

## 4. 分工

**你负责**：开通实例、在控制台开启自定义服务并确认链接、创建备份镜像（依赖装好后）、保证账户余额、演示当天保持开机。

**我负责**：单端口部署脚本、`--proxy-headers` 配置、SSE 与上传体积实测脚本、备份与恢复脚本、开机自检脚本、部署手册。
