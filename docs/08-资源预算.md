## 3. 省钱策略（重要）

1. **开发期不要常驻 GPU。** P2 做 RAG 时只有 embedding / 重排 / OCR 在用，这三者在云端 CPU 上也能跑（查询 100–300ms、重排 20 条约 1.5–4s），用便宜的 CPU 实例即可，贵 GPU 留到 P3 对话联调和 P4 训练。
2. **按天开、按天关。** 联调当天开机，结束即关；关机前确认 Chroma 与 MySQL 已落盘。
3. **训练完立即释放实例**，只把 adapter（几十 MB）下载到本地。
4. **验收期再常驻。** 若演示只在 12/04–12/06，生产实例可只开 3 天，约 ¥180–290。
