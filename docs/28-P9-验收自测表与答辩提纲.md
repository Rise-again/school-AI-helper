## 4. 答辩提纲（建议 8–10 分钟）

1. 选题与目标：校园问答 + 溯源 + 教务，三角色；
2. 技术栈与硬约束：单机 4090、单 worker、vLLM + LoRA、Chroma；
3. 架构：LangGraph 路由 → 级联检索（静态/联网）→ 重排 → 生成 → 落地校验 → SSE；
4. 微调：540 条 SFT、QLoRA r16、基座 vs LoRA 对比；
5. 质量：47+13 评测集、库外拒答 100%、引用 90%；
6. 性能：6 并发 P95 2.58s、限流排队、显存 21.6GiB；
7. 稳定性：六类故障演练、降级表；
8. 安全：越权/注入/上传/密钥/暴露面；
9. 演示：访客、学生、管理员三段；
10. 不足与后续：教务联调、10 并发时延、弱口令、无 systemd。
